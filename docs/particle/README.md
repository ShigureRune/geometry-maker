# PARTICLE MODE v1 — 渦巻き集合

## 使い方
3Dモード → **図形** → **PARTICLE MODE · 渦巻き集合** → **立体を粒子で描く** をONにします。
「アニメーション」から **粒子集合を最初から再生** を押すと、同じシード・同じ配置で演出を再生できます。

## 仕様
- 既存の13種類の立体の**表面**を粒子で表現します。元の3Dオブジェクト生成・密度・種類・カメラを共有します。
- 初期値は**4,000粒子 / 3.2秒 / 渦の強さ1 / 広がり140% / 高さ120% / 揺らぎON**。
- 粒子は各立体のローカルY軸まわりに、渦を描きながら立体の表面へ集まります。回転方向はシードから決まります。
- 集合後は、元の立体と同じ浮遊・回転に追従します。
- 乱数は既存のシード付きPRNGを使用。粒子の開始位置・表面上の着地点・回転方向は同じシードと設定で再現できます。描画フレームでMath.randomは使用しません。
- 再生／一時停止、シーン時計、静止画PNG、既存の3D動画書き出し、設定JSON、自動保存に接続。集合は再生開始から一度だけ実行します。
- デフォルトではOFF。古い3D JSONを読み込んでも勝手にパーティクルが有効になりません。
- 低品質（スマホ自動設定を含む）では粒子数を最大1600個に抑えます。設定値は変更せず、描画量だけ削減します。
- VOIDモードは専用のジオメトリを持つため、PARTICLE MODEの切替は使用できません。VOIDをOFFにすれば再度使用できます。
- 既存の接続線は粒子表示中は非表示とし、元の3Dへ戻ると復元されます。天体や2Dの空間合成・環境は独立して利用できます。

## 実装箇所
- src/three/particle.ts: 設定、検証、シード付き回転方向、シーク可能なイージング
- src/three/ParticleCloud.tsx: 13種の立体の表面から粒子を取得、単一THREE.Points描画と再生時刻に応じた収束
- src/three/settings.ts: 設定JSON互換性
- src/three/ThreeControls.tsx: 操作UI
- src/three/ThreePreview.tsx: 3D描画と保存・再生時計との連携
- src/three/particle.test.ts: 初期値・互換性・入力検証・シード再現・時間補間
