# GALAXY MODE v1 — 巨大銀河

## 起動
3Dモード → 「図形」 → 「GALAXY MODE · 巨大銀河」 → 「巨大銀河を生成する」をON。
オリジナルのPARTICLE MODEやVOIDとの同時描画は行わず、通常の3D図形を銀河に切り替えます。旧プロジェクトではデフォルトOFFです。

## できること
- 中心の恒星密集域／2〜8本の螺旋腕／銀河円盤の厚み／星間ダスト
- 最大30,000個のGPUスタースプライト（軽量モードは描画上限3,600個）
- スターごとの色・明るさ・サイズ・公転速度。紫、青、ローズ、ゴールドの4配色
- ゆっくり回転し、シードによって銀河腕の向き・巻き込み・星の位置が変わる
- 銀河形成の一回きりのアニメーションと「銀河形成を最初から再生」
- シード変更で旧銀河の星を新銀河の星へ補間。自動待機切り替えに連動。3Dアニメーション停止中は現在の時点で停止
- 既存3D PNG書き出し、動画書き出し、設定JSON、自動保存、カメラ操作で使用可能

## 設定
星の数: 1,000〜30,000（初期12,000）
螺旋腕: 2〜8（初期4）
巻き込み: 0.4〜4（初期2.1）
銀河の広がり: 3〜10（初期5.5）
中心核の発光: 0〜200%（初期130）
星間ダスト: 0〜60%（初期20）
回転速度: 0〜2（初期0.6）
色テーマ: violet / blue / rose / gold
シード切替: ON/OFF（初期ON）
切替秒数: 0.5〜15（初期3.5秒。待機画面では待機画面の遷移時間を優先）

## パフォーマンスと設計
銀河生成には独立したシード付き乱数ストリームを使用。生成データをBufferGeometryとして1回転送し、GPU頂点シェーダーが毎フレームの公転とシードモーフを担当します。フレームごとの乱数や大量の独立meshは使用しません。

## 動作確認
npm test
npm run build
npx playwright test tests/three-galaxy.spec.ts

スマホやGPU性能の低い環境では3D描画品質を「軽量」にすると恒星表示数が3,600個以下になります。設定JSON上の希望恒星数は維持されます。
