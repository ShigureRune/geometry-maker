# GALAXY MODE v1 — 巨大銀河

## 起動
3Dモード → 「図形」 → 「GALAXY MODE · 巨大銀河」 → 「巨大銀河を生成する」をON。
オリジナルのPARTICLE MODEやVOIDとの同時描画は行わず、通常の3D図形を銀河に切り替えます。旧プロジェクトではデフォルトOFFです。

## できること
- 中心の恒星密集域／2〜8本の螺旋腕／銀河円盤の厚み／星間ダスト
- 最大30,000個のGPUスタースプライト（軽量モードは描画上限3,600個）
- スターごとの色・明るさ・サイズ・公転速度。紫、青、ローズ、ゴールドの4配色
- ゆっくり回転し、シードによって銀河腕の向き・巻き込み・星の位置が変わる
- 銀河形成の一回きりのアニメーションと「銀河形成を最初から再生」
- シード変更で旧銀河の星を新銀河の星へ補間。自動待機切り替えに連動。3Dアニメーション停止中は現在の時点で停止
- 既存3D PNG書き出し、動画書き出し、設定JSON、自動保存、カメラ操作で使用可能

## 設定
星の数: 1,000〜30,000（初期12,000）
螺旋腕: 2〜8（初期4）
巻き込み: 0.4〜4（初期2.1）
銀河の広がり: 3〜10（初期5.5）
中心核の発光: 0〜200%（初期130）
星間ダスト: 0〜60%（初期20）
回転速度: 0〜2（初期0.6）
色テーマ: violet / blue / rose / gold
シード切替: ON/OFF（初期ON）
切替秒数: 0.5〜15（初期3.5秒。待機画面では待機画面の遷移時間を優先）

## パフォーマンスと設計
銀河生成には独立したシード付き乱数ストリームを使用。生成データをBufferGeometryとして1回転送し、GPU頂点シェーダーが毎フレームの公転とシードモーフを担当します。フレームごとの乱数や大量の独立meshは使用しません。

## v2 実際の渦巻銀河に近い構造
実際のNGC 1566、M51、NGC 1300などのハッブル画像とNASAの解説を参考にした、見た目を優先する近似モデルです。重力を解くN体シミュレーションではありません。

- **対数螺旋の主腕**: 以前の狭く何重にも巻いた同心円状の分布を廃止。デフォルトは「2本の幅広い螺旋腕」で、巻き込みを対数半径に応じて制御します。小さい副腕・分岐・羽毛状のむらも加えます。
- **星の円盤**: 腕の間を空白にせず、古い星を広く分布させる指数関数に近い半径分布を追加。星の数を維持しつつ、銀河の連続したシルエットにします。
- **暖色の中心バルジ**: 小さな黄〜薄橙の中心領域と厚みのある古い星。中心のサイズ・不透明度・発光強度を抑えて大きな白飛びを回避。
- **青い星団・ピンクの星形成領域**: 単純に星を均等配置せず、腕上の複数の星団中心にまとめて配置。大型の弱いスプライトで淡いガス雲を近似します。
- **暗いダストレーン**: 螺旋腕に沿う一部の星の発光を弱め、暗い曲線が現れるようにします。加算描画の制約上、真の光学的吸収・遮蔽はシミュレートしていません。
- **角度と棒状構造**: 銀河円盤の傾斜（初期23°）、腕の太さ、棒状銀河のON/OFFを追加。棒状時は中心付近の星を引き延ばし、腕の起点を棒の端側に寄せます。
- **床を隠す**: 銀河モード中だけ3D床グリッドを描かず、設定値はそのまま保持。通常モードに戻ると元の床設定へ復元。
- **互換性**: 過去の3D設定JSONに追加項目がなくてもデフォルト値でロード可能。既存のPARTICLE MODE・VOID・3D保存/動画は維持。

参考資料（NASA/ESA公式）:
- https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-galaxies/
- https://science.nasa.gov/asset/webb/webb-and-hubbles-views-of-spiral-galaxy-ngc-1566/
- https://science.nasa.gov/asset/hubble/out-of-this-whirl-the-whirlpool-galaxy-m51-and-companion-galaxy/
- https://science.nasa.gov/asset/hubble/spiral-galaxy-ngc-1300/

以前のプロジェクトで腕が4本・中心が明るすぎる設定のままの場合は、「観測写真風（2本腕）に整える」を押すと、2本腕／幅広い螺旋／控えめな中心発光／星数18,000以上の写真風設定へ一括切替できます。配色は保持します。

## v3 銀河が薄い星の輪にしか見えない問題を改善

実際のPNG書き出しでは中心核や銀河腕がほとんど見えず、粒子の細い環が浮いている状態でした。銀河の星の位置だけを調整しても写真のような見え方にはなりません。参考：NASAのM51公式画像 https://science.nasa.gov/asset/hubble/out-of-this-whirl-the-whirlpool-galaxy-m51-and-companion-galaxy/

- **夜空の背景**: 写真風の見た目を優先し、GALAXY MODEがONの間だけデフォルトで濃紺の宇宙背景を描画。元の背景設定は変更しません。「暗い宇宙背景を使う」をOFFにすると設定済みの背景が表示されます。PNG・動画にも同じ表示が適用されます。
- **GALAXY DIFFUSE LAYER**: 一粒ずつの星とは独立したGPUシェーダーの半透明ディスクを追加。黄色い中心のバルジ、緩やかに減衰する星の円盤、青い幅広い2本の腕、淡いピンクの星形成域、濃淡を持つダスト筋をレンダリングします。
- **同一シードの方向一致**: 星粒子の生成器が使うシードの初めの2乱数を共有して、光る腕と星の腕が同じ向きになるようにします。
- **星の視認性向上**: 3Dスターのスプライトを少し拡大、輝度・アルファを調整。軽量表示や1920×1080のPNGでも腕が点線になりにくくします。
- **静止画とアニメーション**: 拡散光層も従来の3D時計に連動。初回形成、星の回転、シード変更時のフェード移行、停止と動画フレーム指定に対応します。設定UIとプロジェクトJSONの形式は変えません。
- **効率**: GPU平面1枚を追加し、星粒子は従来どおり一括描画。30,000個の星を個別のメッシュとして描画しません。
- **正確さの範囲**: ダスト・ガス・星の雰囲気を描いた手続き的なビジュアル表現であり、重力計算や観測波長の物理シミュレーションではありません。
