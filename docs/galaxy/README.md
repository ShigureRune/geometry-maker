# GALAXY MODE v1 — 巨大銀河

## 起動
3Dモード → 「図形」 → 「GALAXY MODE · 巨大銀河」 → 「巨大銀河を生成する」をON。
オリジナルのPARTICLE MODEやVOIDとの同時描画は行わず、通常の3D図形を銀河に切り替えます。旧プロジェクトではデフォルトOFFです。

## できること
- 中心の恒星密集域／2〜8本の螺旋腕／銀河円盤の厚み／星間ダスト
- 最大30,000個のGPUスタースプライト（軽量モードは描画上限3,600個）
- スターごとの色・明るさ・サイズ・公転速度。紫、青、ローズ、ゴールドの4配色
- ゆっくり回転し、シードによって銀河腕の向き・巻き込み・星の位置が変わる
- 銀河形成の一回きりのアニメーションと「銀河形成を最初から再生」
- シード変更で旧銀河の星を新銀河の星へ補間。自動待機切り替えに連動。3Dアニメーション停止中は現在の時点で停止
- 既存3D PNG書き出し、動画書き出し、設定JSON、自動保存、カメラ操作で使用可能

## 設定
星の数: 1,000〜30,000（初期12,000）
螺旋腕: 2〜8（初期4）
巻き込み: 0.4〜4（初期2.1）
銀河の広がり: 3〜10（初期5.5）
中心核の発光: 0〜200%（初期130）
星間ダスト: 0〜60%（初期20）
回転速度: 0〜2（初期0.6）
色テーマ: violet / blue / rose / gold
シード切替: ON/OFF（初期ON）
切替秒数: 0.5〜15（初期3.5秒。待機画面では待機画面の遷移時間を優先）

## パフォーマンスと設計
銀河生成には独立したシード付き乱数ストリームを使用。生成データをBufferGeometryとして1回転送し、GPU頂点シェーダーが毎フレームの公転とシードモーフを担当します。フレームごとの乱数や大量の独立meshは使用しません。

スマホやGPU性能の低い環境では3D描画品質を「軽量」にすると恒星表示数が3,600個以下になります。設定JSON上の希望恒星数は維持されます。


## v2 実際の渦巻銀河に近い構造
実際のNGC 1566、M51、NGC 1300などのハッブル画像とNASAの解説を参考にした、見た目を優先する近似モデルです。重力を解くN体シミュレーションではありません。

- **対数螺旋の主腕**: 以前の狭く何重にも巻いた同心円状の分布を廃止。デフォルトは「2本の幅広い螺旋腕」で、巻き込みを対数半径に応じて制御します。小さい副腕・分岐・羽毛状のむらも加えます。
- **星の円盤**: 腕の間を空白にせず、古い星を広く分布させる指数関数に近い半径分布を追加。星の数を維持しつつ、銀河の連続したシルエットにします。
- **暖色の中心バルジ**: 小さな黄〜薄橙の中心領域と厚みのある古い星。中心のサイズ・不透明度・発光強度を抑えて大きな白飛びを回避。
- **青い星団・ピンクの星形成領域**: 単純に星を均等配置せず、腕上の複数の星団中心にまとめて配置。大型の弱いスプライトで淡いガス雲を近似します。
- **暗いダストレーン**: 螺旋腕に沿う一部の星の発光を弱め、暗い曲線が現れるようにします。加算描画の制約上、真の光学的吸収・遮蔽はシミュレートしていません。
- **角度と棒状構造**: 銀河円盤の傾斜（初期23°）、腕の太さ、棒状銀河のON/OFFを追加。棒状時は中心付近の星を引き延ばし、腕の起点を棒の端側に寄せます。
- **床を隠す**: 銀河モード中だけ3D床グリッドを描かず、設定値はそのまま保持。通常モードに戻ると元の床設定へ復元。
- **互換性**: 過去の3D設定JSONに追加項目がなくてもデフォルト値でロード可能。既存のPARTICLE MODE・VOID・3D保存/動画は維持。

参考資料（NASA/ESA公式）:
- https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubble-galaxies/
- https://science.nasa.gov/asset/webb/webb-and-hubbles-views-of-spiral-galaxy-ngc-1566/
- https://science.nasa.gov/asset/hubble/out-of-this-whirl-the-whirlpool-galaxy-m51-and-companion-galaxy/
- https://science.nasa.gov/asset/hubble/spiral-galaxy-ngc-1300/

以前のプロジェクトで腕が4本・中心が明るすぎる設定のままの場合は、「観測写真風（2本腕）に整える」を押すと、2本腕／幅広い螺旋／控えめな中心発光／星数18,000以上の写真風設定へ一括切替できます。配色は保持します。

## v3 銀河が薄い星の輪にしか見えない問題を改善

実際のPNG書き出しでは中心核や銀河腕がほとんど見えず、粒子の細い環が浮いている状態でした。銀河の星の位置だけを調整しても写真のような見え方にはなりません。参考：NASAのM51公式画像 https://science.nasa.gov/asset/hubble/out-of-this-whirl-the-whirlpool-galaxy-m51-and-companion-galaxy/

- **夜空の背景**: 写真風の見た目を優先し、GALAXY MODEがONの間だけデフォルトで濃紺の宇宙背景を描画。元の背景設定は変更しません。「暗い宇宙背景を使う」をOFFにすると設定済みの背景が表示されます。PNG・動画にも同じ表示が適用されます。
- **GALAXY DIFFUSE LAYER**: 一粒ずつの星とは独立したGPUシェーダーの半透明ディスクを追加。黄色い中心のバルジ、緩やかに減衰する星の円盤、青い幅広い2本の腕、淡いピンクの星形成域、濃淡を持つダスト筋をレンダリングします。
- **同一シードの方向一致**: 星粒子の生成器が使うシードの初めの2乱数を共有して、光る腕と星の腕が同じ向きになるようにします。
- **星の視認性向上**: 3Dスターのスプライトを少し拡大、輝度・アルファを調整。軽量表示や1920×1080のPNGでも腕が点線になりにくくします。
- **静止画とアニメーション**: 拡散光層も従来の3D時計に連動。初回形成、星の回転、シード変更時のフェード移行、停止と動画フレーム指定に対応します。設定UIとプロジェクトJSONの形式は変えません。
- **効率**: GPU平面1枚を追加し、星粒子は従来どおり一括描画。30,000個の星を個別のメッシュとして描画しません。
- **正確さの範囲**: ダスト・ガス・星の雰囲気を描いた手続き的なビジュアル表現であり、重力計算や観測波長の物理シミュレーションではありません。

ブラウザテストのスクリーンショットはGitHub Actionsの `galaxy-v3-visual-proof` artifactへ保存します。

## v4 — 七種類の銀河バリエーション

「3Dモード」→「図形」→「GALAXY MODE」をONにすると「銀河タイプ」が選択できます。v3の古い設定JSONは何も変えずに読み込めて、未指定の銀河タイプはグランドデザインです。

| タイプ | 見た目・生成上の特徴 | 専用パラメータ |
| --- | --- | --- |
| grand_design | 既存の二本腕グランドデザインの形状を維持 | 腕の数・巻き・太さ、棒状ON/OFF |
| barred_spiral | 棒状中心核とそこから伸びる腕（「棒状銀河」に自動切替） | 腕の数・巻き・太さ |
| flocculent | 途切れた短い星形成腕・多数の星団 | 星団のまとまり、枝分かれ |
| ring | 中心と連続したリング状星形成領域、主腕なし | リング半径・幅 |
| elliptical | 古い星が集中する滑らかな楕円体、螺旋腕なし | 楕円率 |
| irregular | 非対称の複数星団とガスの塊 | 不規則さ |
| interacting | 空間的に分離した2銀河と潮汐の尾 | 伴銀河の距離・サイズ・尾の強さ |

星の分布だけではなく、GPUの連続発光レイヤー（GalaxyDiffuse）もタイプごとに異なります。7タイプともシードによる再現性、GPUでの一括描画、時計による回転、シード変更時の変形、PNG/動画/設定JSONの既存エクスポートを維持します。重力を解く物理シミュレーションではなく、観測に着想を得た視覚表現です。相互作用銀河の潮汐の尾もアニメーション上の演出であり、重力計算ではありません。

### すぐ使えるプリセット
「銀河プリセット」から M51風、NGC 1300風、天の川風、雲状の小腕、リング、黄色い楕円銀河、不規則、相互作用の8設定を選べます。タイプ・専用パラメータ・配色の一部を一括設定します。プリセットは特定の銀河の正確な再現ではありません。シードと既存の星数は保持し、各モードの独立設定を不用意に壊しません。

### 確認
- src/three/galaxy.test.ts: 7タイプの再現性・異なる星分布、リング半径、楕円率、伴銀河と尾、設定 validation と旧JSON互換性
- tests/three-galaxy.spec.ts: 7タイプの実GPU描画、タイプ別操作、プリセット切替、JSON往復、既存のシードアニメーション
- Actions の \`galaxy-v4-seven-type-gallery\` に全タイプの画像を記録

## v4.1 — 7銀河の見た目を磨く

NASA/ESAのM51実写で特徴的な、古い星による暖色の核、青い若い星、赤〜ピンクの星形成領域、暗いダスト筋を参考にし、GPU描画の見た目を改善。

- **渦巻・棒渦巻**：腕の明るい芯と外側の淡い腕を分け、輝度が均一な「光る線」に見えないようにしました。星間ガスは3段階のスケールでゆっくり変化するノイズ（細かい正方形模様ではない）を使います。
- **暗いダストレーン**：腕に沿う細い2つの減光筋を導入し、星とガスの光を局所的に弱めて陰影を作ります。ダストを0にしたときは筋の減光は無効です。
- **青い星団とピンク色の星形成域**：ガスの明暗と同じ場所に輝く細かな塊を追加。中心は少し小さく暖かい発光へ調整して白いボール感を減らします。
- **リング銀河**：単色の円形ネオン輪から、雲の明暗・局所的な星形成領域・薄い暗色の筋を持った輪へ。
- **楕円銀河**：腕を作らず、暖かい中心から柔らかく薄まる星の層と粒状感を控えめに追加。
- **不規則・相互作用銀河**：塊ごとのガスの明暗と細かい星形成領域、伴銀河のコンパクトな中心、潮汐の尾のむらを追加。
- **アニメーション**：連続した腕の回転速度を個別の星の半径依存の公転速度に近づけ、長時間の動画で星の腕とガスがズレにくいように改善。
- **互換性**：保存JSON・既存の7タイプ・8プリセット・星数制限・初期化UIは変更しません。

写真のピクセル再現、観測データ処理、質量・重力シミュレーションではなく、NASA画像の特徴を観察したグラフィック表現です。ブラウザテストで7種類の画像を保存して視覚確認します。

## ガスのアニメーションが止まっていた問題の修正

v4.1までは星の粒子だけが3D時計で動き、連続発光のガスレイヤーは渦巻きの腕角度を除いて固定されたシェーダー座標を参照していました。そのため、星雲の濃淡が画面に張り付いたままになり、リング・楕円・不規則・相互作用銀河ではガス模様がほとんど変化しませんでした。

- `GalaxyDiffuse` の半径ごとのガス軌道 `gasOrbit()` を追加。星粒子に近い回転速度で元のガス座標を逆回転サンプリングします。
- 7タイプのガス塊・星形成域・雲ノイズ・星間ダストにガス軌道を適用。相互作用銀河は2つの中心を保ったまま、それぞれの内部のガスと潮汐の尾の発光が流れます。
- 共有する3D再生時計を使い、一時停止・回転速度0で停止。静止画と動画の指定時刻でも再現可能です。
- 実WebGLの開発テストは `?galaxyGasOnly=1` で恒星の点群を隠し、ガスだけを表示して、7種類の再生中のフレーム変化、停止中のフレーム固定を検証します。検証用の表示切替は本番ビルドでは無効です。

設定JSON・既存作品・星数・銀河プリセットに変更はありません。

## 星の腕とガスの腕の位置・回転方向を同期（軌道同期修正）

以前のバージョンは星粒子とガスのGPU描画で、腕中心の式、回転速度、腕幅をそれぞれ別々に定義しており、相互作用銀河では中心座標の縮尺も異なっていました。このためガスが流れていても星の腕と重ならず、粒子の公転の見え方も不整合になり得ました。

- `galaxy-motion.ts` に共通の対数腕中心、半径依存の角速度、左右の回転方向、バー半径を集約。星の生成とガスのシェーダーは同じ定数から計算します。
- 星粒子は `+角速度×時刻` で前進し、ガスの模様は `-角速度×時刻` で逆回転サンプリングします。どちらも画面上では同じ方向へ流れます。
- 星粒子のWebGLマテリアルへ3D時計を毎フレーム明示的に反映。星を非表示にしたガステストに加え、**ガスを非表示にした星だけのテスト**で、星自体が回ることを確認します。
- 相互作用銀河では主銀河・伴銀河の星がそれぞれ自身の核を中心に公転し、ガスも同じ縮尺を使用します。
- 腕幅をそろえ、ガスの明るい帯が星の分布から離れた太い輪になりにくいようにしました。
- リング・楕円・不規則などを含む7種類の銀河、回転速度0、停止・再生、既存のプロジェクトJSONに引き続き対応。

テスト: `src/three/galaxy-motion.test.ts`（共有式・腕の一致・順方向/逆方向の一致・伴銀河の公転中心）、`tests/three-galaxy.spec.ts`（星だけの動き、一時停止と速度0）。
