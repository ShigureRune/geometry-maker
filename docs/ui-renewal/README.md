# 設定UIのリニューアル

## 現在の設定ハブ

2D/3Dの生成設定は、専用の**設定一覧**と**個別設定画面**に分離しています。

1. 左側の設定一覧（スマホではプレビューの下）に7つのカテゴリーを縦に表示します。
2. 各行の右側にあるチェックボックスをオンにすると、設定一覧が左に、詳細画面が右からスライドして切り替わります。カテゴリー名・行を押しても開けます。
3. 詳細画面の **「← 設定一覧へ」** で一覧に戻れます。詳細画面の入力・書き出し・再生状態は画面遷移によって初期化されません。
4. モバイル下部の **「設定」** は一覧へ戻ります。コマンド検索や **「書き出しへ」** からは直接詳細画面を開けます。
5. ページを下にスクロールすると右下に **「↑ TOP」** が現れ、押すとページ最上部へ戻ります。スマートフォンでは固定の操作ドックより上に配置します。

| カテゴリー | 設定内容 |
| --- | --- |
| 図形 | シード、構図、比率、密度、生成方式、3Dの主な構成 |
| 背景 | 単色・グラデーション、グリッド、3Dの背景や空間 |
| カラー | 背景・図形の色、シード連動配色、テーマ |
| 文字 | 2D文字、レイアウト、登場演出（3D・魔法陣モードでは選択不可） |
| 装飾 | 線、発光、3Dマテリアルやエフェクト |
| アニメーション | 成長・待機・3Dモーション・タイムライン |
| 書き出し | PNG/SVG、MP4/WebM、JSON保存・復元 |

## 動作とアクセシビリティ

- 既存の詳細設定は非表示中もReact上に保持し、切り替えだけで入力・状態を破棄しません。
- スライド移動はCSSで実装し、視覚効果を減らすOS設定ではアニメーションを使いません。
- チェックボックスから詳細画面を開くと「設定一覧へ」ボタンへキーボードフォーカスを移し、戻ると最後に開いたカテゴリーのチェックボックスへ戻します。
- 設定一覧と詳細画面のうち、表示していない方は`inert`と`aria-hidden`で操作対象から外します。
- 設定ハブの開閉は画像生成や保存設定JSONの形式を変更しません。

従来は横方向に並ぶ7カテゴリーのボタンで詳細を選択していました。今回の変更で一覧は縦型になり、カテゴリ選択と詳細設定を独立したスライド画面で扱えます。

## 検証
