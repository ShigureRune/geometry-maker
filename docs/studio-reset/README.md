# 設定の初期化（2D・3D・各モード）

「図形」カテゴリーの下部にある「設定の初期化」から実行します。操作前に確認ダイアログが表示され、キャンセルすると何も変更されません。

- **すべて初期化**（2D・3D共通）：シードを新しく作り、2D・3D設定、配色、画面テーマ、パネル幅や開閉状態、現在の端末に自動保存していた編集内容を初期状態へ戻してページを開き直します。ダウンロード済みのJSON・画像・動画ファイルは変更しません。別アプリの保存データも消しません。
- **2D設定を初期化**：図形の種類、魔法陣、文字、成長アニメーション、装飾、配色、縦横比、密度を初期状態へ戻します。シードは維持。背景・配色・密度・縦横比は2D/3Dで共有されるため、3D側の共通値も変わります。
- **3D設定を初期化**：GALAXY／PARTICLE／VOID、質感、空、床、ネットワーク、カメラ、スタンバイ、アニメーション等を最初の3D設定へ戻します。シードと2D設定は維持。カメラと3D時計は初期化。
- **GALAXY設定を初期化**：銀河モードの各項目を既定値へ戻し、ON/OFF状態・シード・他モード設定を維持。
- **PARTICLE設定を初期化**：粒子モードの各項目を既定値へ戻し、ON/OFF状態・シード・他モード設定を維持。
- **VOID設定を初期化**：VOIDモードの設定を大規模コズミックウェブの初期値へ戻し、ON/OFF状態とシード・他モード設定を維持。ONなら構図とカメラも初期化。

動画書き出し中・待機画面遷移中は誤操作を避けるため初期化ボタンを無効にします。

**自動保存と再読込**：全初期化ではpagehideによる自動保存が消去済みデータを復活させないよう、リセット中だけ保存を停止してから、このスタジオ自身のローカル保存キーだけを削除します。リロード後は新しい既定状態として自動保存されます。
