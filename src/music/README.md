# Seed Music Studio

ヘッダーで「Musicモード」を選択するか、URLに `?mode=music` を付けて開きます。
音楽のシードと設定はこの画面で管理し、既存の幾何学プロジェクトのシードや設定には反映しません。

- 「作曲設定」でシードやジャンルを選び、「シードから生成」を押します。「全曲再生成」は固定されていないパートの変奏番号を進めます。「パート再生成」は選択中のトラックだけが対象です。コードを変えるときはメロディーとベースを同時に再生成するか選べます。
- 横スクロールでは音符をドラッグして移動し、右端で長さを変えます。Shift、Ctrl、⌘を押しながらクリックすると複数選択できます。空白のダブルクリックまたは「音符を追加」で音符を作れます。落下ノーツでは一時停止してクリックし、「選択音符」の数値で編集します。スマホでは「作曲設定」「トラックと音符」「書き出し」をタップして展開します。
- 「音符操作」からコピー、貼り付け、クオンタイズ、取り消し、やり直しができます。再生位置のスライダーは両ロールで共通です。範囲ループとMP3の範囲指定には、開始小節と終了小節を使います。
- JSONは編集した音符と元シード、変奏番号、パートの固定、ミキサーを保持します。MIDIはFormat 1で、初期設定ではミュート／ソロにかかわらず全パートを含みます。MIDIの音色は読み込み先の音源で変わります。
- MP3はブラウザ内のオフラインレンダリングで生成します。PCMは約6秒ずつ処理し、Workerでステレオにエンコードします。範囲末尾で続く音符はそこで止め、範囲内で終わった音符のリリースを含めます。Web Audioを利用できるブラウザが必要です。

現在の作曲版は `seed-music-v1` と互換性を維持し、4/4拍子、最大128小節、4・6・8パートを選択できます。標準の4パート（メロディー・コード・ベース・ドラム）に加え、6パートでアルペジオとパッド、8パートで副旋律とリズムシンセが加わります。4パート時の元シード生成はそのままです。既存の4パートJSON（`trackCount` 未設定）も読み込めます。

- 曲の長さはBPMで変わります。128小節ならBPM120で4分16秒、BPM60で8分32秒です。長尺や多トラックは端末性能によりMP3生成時間が伸びるため、まず短い曲で確認することを推奨します。
- 演奏パート数を減らした場合、対象外の追加パートは現在の曲から外れます。必要な場合は先にプロジェクトJSONを保存してください。
- 同じトラックの同じ音程を重ねる編集は、MIDI書き出しで音の終点が曖昧にならないよう制限しています。別トラックでは同時に鳴らせます。音源はコード内で合成し、外部の音源素材を使いません。

MP3エンコーダーのライセンスとソース参照は [配布情報](../../public/licenses/seed-music-encoder.txt) にあります。

## 落下ノーツの多重表示・エフェクト

- 落下ノーツでは初期状態で**全パート同時落下**を有効にしています。トラック別カラー（各トラックの色設定に同期）、音程別カラー、単色を切り替えられます。
- **重複ノーツを左右分離**で、同じ音程で時間が重なるノーツを鍵盤レーン内のサブレーンへ振り分けます。レーンは曲全体から計算するため、再生やシークで急に位置が入れ替わらないようにしています。小さいスマホ画面では88鍵モードのレーンが細くなる場合があります。
- 「表示とグリッド」で**残像・パーティクル・着地フラッシュ・波紋・長音のきらめき**を切り替えられます。発光・残像の強度は0〜100%、エフェクト品質は低・中・高です。低品質は負荷を抑えるため一部の高コスト演出を省きます。
- 「全パート同時落下」をオフにすると、横スクロールと同様に選択トラックおよび追加表示を有効にしたトラックのみ表示します。
- これらは**描画専用の設定**です。楽曲のシード・音符・再生・MP3・MIDI出力には影響しません。発音位置とヒット演出は再生位置から決定し、途中シークでも過去の粒子が残らない方式です。
